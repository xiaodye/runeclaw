Project Naming Direction

Three name + logo directions for this local AI Agent runtime. Click one if it feels right.

A. Nexus Agent

强调工具、记忆、RAG、MCP、子 Agent 的连接中枢感。稳、技术感强，适合 CLI/Agent runtime。

B. OrbitKit

强调本地工具围绕模型运行的编排感。名字短，产品感更强，但比 Agent runtime 稍微抽象。

C. RelayCore

强调多工具、多通道、多 Agent 的调度核心。更工程化，适合后续插件系统和企业集成扩展。
